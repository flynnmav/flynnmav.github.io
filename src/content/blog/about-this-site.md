这个网站是 Leyan Liu 的个人学术主页与科研技术博客，主要用于整理无人机自主系统、机器人学、智能控制、轨迹规划、多无人机协同、强化学习，以及人工智能与具身智能方向的学习记录。

目前公开内容以研究主题和学习笔记为主。教育经历、电子邮箱、GitHub、Google Scholar、论文和具体项目成果等身份信息，在得到核实并写入站点配置之前不会展示。网站中的“待完善”代表资料尚未补充，不代表已经完成或公开发布的研究成果。

## 技术架构

网站采用 [Astro](https://astro.build/) 与 TypeScript 构建，文章由 Markdown 文件驱动，并通过 Astro Content Collections 进行字段校验和页面生成。数学公式由 remark-math 与 KaTeX 处理，代码块在构建阶段完成语法高亮。

站点以静态文件形式生成，不需要数据库或长期运行的应用服务器。源码计划由 GitHub 托管，并通过 GitHub Actions 构建到 GitHub Pages；正式域名为 `leyanliu.com`。这一结构便于版本管理，也让文章能够与代码一起审阅和维护。

## 内容原则

这里的文章会尽量区分概念推导、代码示例、仿真观察和真实实验结果。学习笔记用于记录理解过程，不能替代经过同行评议的论文、设备手册或安全规范。涉及飞行控制的示例需要在仿真环境中验证，并配合独立的安全保护，才能进一步考虑真实平台测试。

文章中的外部资料会优先链接到项目官方文档或原始来源。若内容后来发生修订，页面会保留初始发布日期，并在站点数据中记录更新日期。
