# 刘乐延 - 个人主页

基于纯 HTML/CSS/JS 的单页个人学术网站。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署

**Gitee Pages**：仓库 → 服务 → Gitee Pages → 选择 master 分支 → 启动

**GitHub Pages**：推送到 GitHub 仓库 → Settings → Pages → 选择分支 → 保存

## 自定义内容

- **个人信息**：编辑 `index.html` 中的文字内容
- **颜色主题**：修改 `style.css` 中的 `:root` CSS 变量
- **项目展示**：在 `index.html` 的 `#projects` 区域增删 `.project-card`
